# WorkBuddy 授权唤醒作业指南(SOP)

> 2026-10-17 定稿 · 数据全部来自 workbuddy 侧实测(2026-10-17 08:36 四问回答)
> 目标:**任何一侧醒来,照本指南 3 分钟内恢复授权;且绝大多数时候你根本不需要它。**

## 0. 结论先行(2026-10-17 实测)

- **主链路零人工授权**:CLI 未登录状态下 e2e 1.3s 跑通(老徐亲测)——**不需要任何 CLI 授权**
- **GUI 登录态 ≥20-24 天免重登、无定期确认**(凭证容器 2026-09-23 创建至今活着)
- **Gateway 密码每次实例启动轮换,适配器 PEB 现取天然规避**——任务中途换密码不会发生
- **唯一的人工门:20+ 天一次的 GUI 重登**。触发频率极低,3 分钟流程足够,**不做复杂自动化**

## 1. 授权链四层(哪层要人)

| 层 | 机制 | 要人吗 |
|---|---|---|
| ① Gateway 密码 | 实例启动随机生成,适配器每任务 PEB 现取 | ❌ 全自动 |
| ② 连接即授权 | 建流时 connection-id+session-token 本地环回换发 | ❌ 全自动 |
| ③ GUI 账号登录态 | keyblob 凭证,20+ 天长效 | ⚠️ **20 天一次重登** |
| ④ 模型配额 | 429=额度(非授权),到点重置 | 等重置/换模型 |

## 2. 30 秒诊断:看到什么做什么

| 任务 summary / stderr 现象 | 判定 | 动作 |
|---|---|---|
| `Error: 429 您的使用量已超出频率限制,将在 HH:MM 重置` | **链通,仅配额** | 等重置(探针循环自动复验);急就换模型 |
| `密码: 无(runs API 会 401)` → create_run 401 | PEB 取不到密码 | §3 |
| `401` / `Authentication required`(来自 gateway/模型侧) | GUI 登录态过期(20+天没遇到) | §4 |
| `stream 关闭未见终态,兜底 end_turn` | 任务期间 gateway 重启了(罕见) | 重拨即可,结果丢失不挂死 |
| `ECONNREFUSED` | gateway 端口没监听 | GUI 没开/绿模没起,见《绿模启动》 |

## 3. PEB 取不到密码(密码:无)

1. 确认 WorkBuddy GUI 在运行(gateway 是 GUI 本体)
2. 确认绿模在:`启动绿模.vbs` 或哨兵自拉(见频道 04:05 消息)
3. 重拨探针:PONG 任务 → 预期 succeeded
4. 仍失败 → 找 workbuddy 侧(gateway serve 进程的 env 结构可能变了,它的 PEB 读取要跟着修)

## 4. GUI 登录态过期(20+ 天一次)

1. 老徐在 PC 打开 WorkBuddy GUI → 出现登录框 → **正常登录一次**
2. 无需"记住登录"勾选(产品默认长效)、无需定期确认
3. 重拨 PONG 验证 → succeeded 即恢复
4. **登一次,20 天无忧**

## 5. 死路记录(别再投资)

- **CLI OAuth 授权**:今晨实测——浏览器走完授权、CLI 拿到 userinfo,但**凭据不落盘**,新进程仍报未登录。此路不通,归档。
- 任何"自动刷新登录态"的设想:产品不提供 CLI/API 刷新路径,放弃。

## 6. 监控告警(已就位)

探针循环 v2 自动分级:429→[配额]告警继续盯 / 401→[授权]告警 / 连接类→[连接]告警,全部落 `ops/alerts.log`;**只有干净真 PONG 才触发"全绿"通知**。授权类问题不用人盯日志。
