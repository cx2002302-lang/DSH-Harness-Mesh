# 新节点接入指南(harness-mesh · 通用)

> 适用:任何一台要接入的机器(Windows/Linux 均可,绿色模式,无服务无 admin)。
> 目标:一台新机器从零到可被 208 派活,≤5 分钟。

## 第 1 步(主控侧,208):发入网码

```bash
/home/myxia/.local/bin/ann-ctrl bootstrap create --user=mesh \
  --max-uses=1 --expires=24h --tags=tag:agent \
  --data-dir=/home/myxia/.local/share/ann-ctrl
```
记下 **Short code**(8 位;注意:CLI 的短码解析 bug 已修,短码即可)。

## 第 2 步(新机器):拷包+填两个文件

1. 把本目录整个拷到新机器(如 C:\hm-green\)
2. `plugs.template.json` → 改名 `plugs.json`,填好:
   - `plugId` = `<计算机名>-<harness类型>`(如 MYPCA-opencode;命名规:计算机名+harness 类型)
   - `command` = 该机 harness 的 CLI **完整路径**(如 `C:\...\codebuddy.exe`、`/usr/local/bin/opencode`)
   - `args` 一般 `["--acp"]`;若 CLI 有内置端口冲突,加 `--port`(见排错)
3. `bootstrap.env.template` → 改名 `bootstrap.env`,填 `CODE`(第 1 步的短码)和 `HOSTNAME`(计算机名)

## 第 3 步(新机器):跑起来

双击 `一键入网.bat`(Linux: `python3 guardian.py`)。
- 首次自动 bootstrap 入网 → 看到 Tailnet IP → 自动进入看护(ann-agent + harnessd 常驻)
- 开机自启(可选):Windows 把 bat 快捷方式放 `shell:startup`;Linux 用 systemd --user 或 @reboot cron

## 第 4 步(主控侧):登记+验证

```bash
# ① 看新节点(计算机名自报)
/home/myxia/.local/bin/ann-ctrl node list --data-dir=/home/myxia/.local/share/ann-ctrl
# ② 补 tag(大小写 bug 未修前,新节点常在 mesh 用户;用 Web API 打):
#    POST http://127.0.0.1:8445/api/v1/nodes/{id}/tags {"tags":["tag:agent"]}
# ③ 登记 mesh 节点(API):name=<计算机名>-<harness>, type=acp-plug,
#     address=<tailnet IP>:7080, plugId=<同上>, socks=127.0.0.1:11090
# ④ 派探针任务验证
```

## 排错

| 现象 | 处理 |
|---|---|
| 入网失败 401 | 码过期/用超;回第 1 步重发(注意 CLI 一次调用消耗一次额度) |
| 任务 ACP connection closed | 看对端 guardian 窗口的 CLI stderr;常见:未登录 / CLI 抢内置端口(plugs.json args 加 `--port 5888` 或 `0`)/ command 路径错 |
| 拨不通 | IP 漂移:以 ctrl node list 的 IP 为准更新节点 address |
| health unknown | 对端 harnessd 没起:看 guardian.log;或节点没打 tag(ACL 拒) |
