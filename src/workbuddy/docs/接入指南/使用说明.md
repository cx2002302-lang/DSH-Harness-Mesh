# workbuddy 绿模接入包(Windows)

把本文件夹(\\<LAN-IP>\<MESH_ROOT>\wb-green)拷到你电脑任意位置,例如 C:\wb-green。
无需安装、无需管理员权限;三个文件各司其职:

| 文件 | 作用 |
|---|---|
| ann-agent.exe | ANN 数据面(tailnet/WireGuard),把本机 7080 端口插上内网 |
| harnessd.py | 插头协议服务端,管理本机 harness(workbuddy) |
| guardian.py | 看护上面两个进程,崩溃自动拉回 |

## 第 0 步:确认有 Python 3
打开 cmd 运行 `python --version`;没有就去 python.org 装(勾选 Add to PATH)。

## 第 1 步:一次性入网(只需做一次)

**懒人版**:直接双击 `一键入网.bat`(自动填计算机名,入网后接着启动 guardian)。
手动版(下面)效果相同:
cmd 进入本文件夹(如 C:\wb-green),执行:
```
set ANN_AGENT_DATA_DIR=%CD%\ann-data
ann-agent.exe bootstrap --server=http://<ANN_SERVER>:8444 --code=<BOOTSTRAP_CODE> --hostname=<你的计算机名> --forward 7080=127.0.0.1:7080
```
- `<你的计算机名>` 用英文计算机名(cmd 里 `hostname` 可查)
- 看到 `Tailnet IP`(100.64/10 CGNAT 网段,具体以 ann-agent 输出为准) 即入网成功,按 Ctrl+C 停掉(配置已存本目录 ann-data\)

## 第 2 步:日常运行
以后每次开机跑 `python guardian.py`(一键版第 3 步已自动启动)(或 cmd 里 python guardian.py)。
两个进程看护起来后保持常驻即可——主控会经内网直连你的 7080 派活。

开机自启(可选):按 Win+R 输入 `shell:startup`,把 guardian 的快捷方式放进去。

## 第 3 步:回报
告诉我「绿模跑起来了」,我在 208 侧拨你的 tailnet IP:7080 做连通性测试,
通过后登记 workbuddy 节点,之后就能从 DSH/飞书 @workbuddy 派活。
