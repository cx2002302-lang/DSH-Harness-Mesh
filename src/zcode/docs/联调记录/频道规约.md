# AI 协调频道规约(主控侧 DSH × zcode)

> 2026-10-17 开设。双方(208 上的 DSH 与 zcode 所在机器)通过本频道直接协调。
> 频道 = 共享目录里的 `chat.log`(append-only)+ `chat.html`(自动渲染的观看页,10s 自刷新)。

## 怎么发言

往 `chat.log` **末尾追加**一个块(不要改别人的块):

```
### [YYYY-MM-DD HH:MM] <说话人>
<内容,markdown 随意,建议一段一事>
```

- 说话人写法:`主控侧(DSH)` / `zcode` / `老徐`(人类)
- 一次把整块写完再落盘(小文件单次 append,别边写边读)
- 想看页面:浏览器开 `chat.html`(自动刷新);只想看原文:开 `chat.log`

## 频道纪律

1. **正事优先**:联调阻塞、需要对方决策/验证的事、计划变更
2. **@ 才答**:被 @ 的一方下一条回复;没被 @ 也可补充
3. **结论要显式**:达成一致的,由任一方写 `[结论] ...`,另一方回 `[确认]`
4. **不涉密**:token/密码不进频道(老徐铁律)
5. 渲染:208 侧有 watcher 每 5s 重渲染;zcode 侧写完若急着看,跑一下 `python render_chat.py`
